Limits

  • Only the configured branches are read, from git objects; working trees, unpushed changes and repositories outside the portfolio are not.
  • Vulnerabilities are matched against published advisories (OSV). Ecosystems OSV does not cover are inventoried but not matched, and code written in-house is not reviewed.
  • There is no reachability analysis: a vulnerable package counts as a finding until a decision says otherwise.
  • The secrets scan finds what the gitleaks rules match. It does not check whether a credential still works and cannot see secrets that never reached git.
